## 🌿 Design Direction & Tokens
- **`--ink: #1F2E22`** (Deep green-black text)
- **`--forest: #2F5233`** (Primary brand color, drawn directly from the clinic's logo)
- **`--sage: #7FA173` / `#EAF2E8`** (Secondary soothing botanical green)
- **`--ivory: #FAF6EC` / `#F4EEDF`** (Warm ivory background avoiding generic AI terracotta clichés)
- **`--turmeric: #C08A28`** (Turmeric gold accent for badges, focus states, and CTAs)
- **Typography:** *Cormorant Garamond* (Serif display headlines) + *Plus Jakarta Sans* (Legible modern sans for body and clinical charts)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Development Mode
```bash
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
The optimized static build is generated into `dist/`.
